# Live Translate 使用指南

本指南描述目前正式的 Host Local-only 錄製與 Viewer 即時字幕流程。**RC1 尚未通過正式驗收**：已實作的操作不等於跨裝置、真實麥克風及 Chrome／Safari 實機情境都已驗收，詳見[測試狀態](TESTING.md#issue-41-rc1-acceptance-status-2026-11-09)。

## 1. 登入與建立會議

使用符合部署環境授權規則的 Google Workspace 帳號登入。若帳號處於待核准狀態，先完成管理員核准；Viewer 的分享連結也受會議授權限制。進入會議管理，建立會議並設定名稱、來源／目標語言、錄音與播放選項；儲存設定後可產生 Viewer 連結或 QR code。建立／分享會議**不會**自動啟動麥克風或 Gemini Live 工作階段。

## 2. 字典與字幕調整

在會議設定的「詞彙設定」中選取共用詞彙，或新增／編輯本場會議詞彙；介面也提供 CSV、JSON、XLSX 匯入預覽，選取後仍須儲存會議設定才會套用。詞彙用於後續字幕與翻譯校正：儲存成功後，新接收的 Turn／Cue 會使用更新的本機校正快照；既有已完成 Cue 不會因修改字典而全部自動重寫。錄製中的 Gemini 指令語言／字典變更依下一個正常 Segment 邊界生效，勿把畫面上的詞彙儲存等同於重啟錄音。

即時字幕區顯示原文與譯文，提供「回到最新字幕」及複製文字等檢視操作。現行正式頁面沒有可供使用者逐字手動改寫已儲存 Cue 的通用編輯器；若需要調整專有名詞，請使用會議字典並確認後續字幕結果。翻譯屬模型輸出，重要內容仍須人工核對。

## 3. Host 錄製控制

會議經過時間從本分頁首次成功開始錄製起算；停止錄音、繼續及同分頁重新載入不會重設。成功結束會議後清除顯示計時。此數字僅供介面參考，不代表實際錄音時長，也不寫入 Meeting metadata。

1. 開啟會議的即時字幕頁，按 **開始錄製**，允許瀏覽器麥克風權限，並依介面提供該次 Live 翻譯使用的 Gemini API key。
2. 錄製中按 **停止錄音** 會暫停並持久化當前本機 PCM Journal、Cue 與 Checkpoint；暫停期間不收集 PCM。按 **繼續** 會沿用同一筆錄製並建立後繼 Segment。Meeting 尚未結束前，可重複停止錄音及繼續。
3. 錄製中切換到應用程式內其他頁面，會先完成同一暫停程序；若暫停失敗，會留在錄製頁並顯示錯誤。瀏覽器刷新或強制關閉仍依賴本機恢復機制。**結束會議** 會先完成本機耐久化，再提交完成狀態；完成後不可再於同一 Meeting 錄製。
4. 若封存、Checkpoint 或完成狀態提交失敗，先閱讀畫面錯誤並保留同一瀏覽器的資料；重新載入的恢復依賴本機 OPFS／IndexedDB。不要清除網站資料來排除這類錯誤。

## 4. Viewer 分享與跨裝置觀看

Host 在會議設定取得觀看連結／QR code，傳給獲授權的 Viewer。Viewer 開啟連結後，透過授權 API 與 WebRTC signaling 建立 DataChannel，接收 Host 當下送出的字幕、快照及必要的重播事件。Viewer 不控制 Host 麥克風，也不能從 Supabase 下載或恢復 Host 的 PCM、錄音或 Transcript。跨網路、TURN relay 與斷線重連的實機驗收仍未完成；若未顯示字幕，先檢查會議狀態、分享授權及連線狀態。

## 5. 匯出與本機資料清理

Host 結束後，在**同一瀏覽器、同一來源、保留期限內**開啟會議詳情，可下載可用的本機音訊，並選擇原文／譯文及 TXT、SRT、VTT 格式匯出已儲存字幕。沒有可匯出文字時，介面不會產生空白字幕檔；音訊匯出需有完整、可解碼的本機區塊。Viewer 的即時觀看權限不等於取得這些匯出內容。

End 後內容有固定 **30 分鐘** 存取期限。期限到達後，普通使用者／Viewer 的內容讀取失效；Host 的 OPFS／IndexedDB 清理可能在瀏覽器重新開啟時補做，失敗時可依既有流程重試。雲端仍保留必要的會議設定、字典與授權 metadata。手動清除網站資料會立即失去本機錄音與恢復能力，且無雲端備份可供還原；清理前先完成所需下載。

## 6. 已實作與待驗收

目前有 Local-only 錄製、停止錄音／繼續／結束會議、本機恢復與匯出、字典、Viewer DataChannel 字幕的程式路徑及部分自動化證據。RC1 仍為 `BLOCKED`：40 分鐘錄製、Cloud Zero Write、11/11 Evidence Checks 已通過；40 與 130 分鐘功能錄製均通過，但 RAM Gate 仍失敗；一般使用者跨裝置實機、真實麥克風、Chrome／Safari 裝置矩陣尚未完成。不要將「功能已存在」解讀為「正式驗收 PASS」。
