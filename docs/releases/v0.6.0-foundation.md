# v0.6.0 Foundation Milestone

## Overview

Phase 2 Foundation establishes the core realtime translation workflow, transcript lifecycle, connection resilience foundation, session history, and export capabilities without introducing durable storage or backend persistence.

## Completed Capabilities

- Transcript Engine
- Transcript Export
- Audio Input Device Selection
- Session Lifecycle
- Connection Resilience Phase 1
- Failure Classification
- Retry Policy
- Reconnect Controller
- Controlled `unexpected_close` reconnect
- Failure-state mapping
- Session Records
- History List
- Session Detail
- Saved Session Export

## Architecture Snapshot

- Transcript Engine owns normalized `TranscriptItem` creation, ordering, and final/partial state handling.
- Session Repository owns the boundary for session records and transcript-item storage without selecting a durable engine.
- Export Layer consumes saved transcript items and formats TXT, SRT, and VTT without mutating session state.
- Connection Resilience owns failure classification, retry policy, reconnect orchestration, and recovery UX policy.
- Session Lifecycle owns state transitions, cleanup rules, close reasons, and UI state mapping that history and resilience build on.

These boundaries keep live-session control, transcript handling, export, and history separate while durable persistence remains unresolved.

## Capability Boundary

- Durable storage
- Backend persistence
- Search

- Delete
- Analytics
- Diagnostics dashboard
- Access control
- Token refresh
- Proactive reconnect

- Provider reconnect

## Deferred

These items remain intentionally deferred:

- `token_expired` reconnect
- network reconnect
- provider reconnect
- microphone reconnect
- proactive token refresh
- IndexedDB / `localStorage` adapter
- Backend storage
- Usage Metrics
- Diagnostics
- Settings
- Transcript Search
- Audio Output Selection
- AudioWorklet migration

## Known Limitations

- History is memory-only.
- Refresh clears records.
- Export is frontend-only.
- Transcript content may contain sensitive data.
- There is no cross-device history.
